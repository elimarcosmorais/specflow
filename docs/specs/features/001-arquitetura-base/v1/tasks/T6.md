## 1. Objetivo

A feature `internal/features/preferences` está completa: carrega o tema e o idioma do
`config.json` (com os padrões da primeira execução), guarda as mudanças com gravação atômica e
expõe `PUT /api/preferences`.

## 2. O que fazer

- `preferences.go`:
  - `Preferences{Theme, Language}`.
  - Os valores válidos: tema `light`, `dark` ou `system`; idioma `pt-br` ou `en`.
  - O tema padrão: `system`.
- `errors.go`, com `apperr` e os status de §3.2:
  - `preferences.theme_invalid` (field `theme`);
  - `preferences.language_invalid` (field `language`);
  - `preferences.save_failed`.
- `repository.go`: interface `Repository` com `Load` e `Save`. O `Load` precisa deixar o serviço
  distinguir **arquivo ausente** de **conteúdo inválido**, porque §4.3 trata os dois de forma
  diferente.
- `file_repository.go`:
  - `NewFileRepository(path)`.
  - `Save` grava JSON UTF-8 indentado com 2 espaços, num arquivo temporário na mesma pasta, e
    depois renomeia.
  - O `Load` precisa funcionar sozinho: o `main.go` (T10) o chama para descobrir o idioma do
    diálogo fatal (§6.1, passo 2).
- `service.go`, `NewService(repo, detectLanguage func() string, logger, onChange)`:
  - `Load()`, conforme §4.3:
    - **ausente** → `system` + `detectLanguage()`, `Save` e log `config.created`;
    - **JSON inválido** → os mesmos padrões, `Save` e log `config.invalid` (WARN);
    - **um campo inválido** → só esse campo volta ao padrão, `Save` e log `config.invalid`.
  - `Get()` devolve o valor atual. Ele é chamado a cada requisição (`cfg.Language`, T10), em
    goroutines diferentes das do `Update`: proteja o valor em memória para acesso concorrente.
  - `Update(p)`:
    - Valida o tema antes do idioma (CT-32: `{"",""}` → `theme_invalid`).
    - Em erro de validação: nenhum `Save`, e `Get()` fica inalterado.
    - Falha no `Save` → `preferences.save_failed`, com a causa.
    - Sucesso: chama `onChange` uma vez e loga `preferences.updated theme=… language=…`.
- `handler.go`, `Routes(s)`: `PUT /api/preferences` (protegida) → `DecodeJSON` de
  `{theme, language}` → `Update` → `200` + `{theme, language}`.
- O núcleo (`preferences.go`, `errors.go`, `repository.go`, `service.go`) não importa
  infraestrutura (§2.2).
