## 1. Objetivo

A feature `internal/features/system` responde `GET /api/health`, que é público e responde
mesmo com o banco fora do ar, e `POST /api/system/open-logs-folder`, que abre o Explorer na
pasta de logs.

## 2. O que fazer

- `service.go`:
  - Interfaces `Pinger { Ping(ctx) error }` e `FolderOpener { Open(path string) error }`.
  - Erro `system.open_logs_failed` (`apperr`, status `500`).
  - `NewService(version, pinger, opener, logsDir, logger)`.
  - `Health(ctx)` devolve `{version, database}`. Erro no `Ping` vira `"unavailable"`, nunca um
    erro.
  - `OpenLogsFolder()` chama `opener.Open(logsDir)`. Em erro, devolve
    `system.open_logs_failed` com a causa.
  - Não importa `internal/platform/*`: o `db.Pinger` (T4) satisfaz `system.Pinger`, e quem liga
    os dois é o `main.go` (T10).
- `opener_windows.go`: `ExplorerOpener{}.Open(path)` executa `explorer.exe <path>` com
  `exec.Command(...).Start()`, e não `Run` (§3.3.5).
- `handler.go`, `Routes(s)`:
  - `GET /api/health`, com `Public: true` → `200` + `{version, database}`;
  - `POST /api/system/open-logs-folder`, protegida → `204` sem corpo.
